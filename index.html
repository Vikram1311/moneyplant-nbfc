यह पेज Google Apps Script ऐप का सेटअप बताता है। असली ऐप Google Apps Script के लिंक से खुलेगा।

  1. अपनी Google Sheet खोलें और Extensions → Apps Script चुनें।
  2. इस GitHub repository से Code.gs और Index.html की सामग्री Apps Script में बनाए गए समान नाम के files में डालें।
  3. Apps Script में Project Settings → Script Properties में ADMIN_NAME, ADMIN_MOBILE और ADMIN_PASSWORD जोड़ें। अपना असली पासवर्ड केवल वहाँ रखें, GitHub में नहीं। पासवर्ड कम से कम 8 अक्षर का हो।
  4. Code.gs में setupAllSheets चुनकर Run करें और Google की अनुमति दें।
  5. Deploy → New deployment → Web app चुनें। Execute as: Me; access: अपने उपयोग के मुताबिक सीमित रखें। फिर Deploy दबाकर ऐप का लिंक खोलें।
  6. लॉगिन के बाद एडमिन पेज से सदस्यों को जोड़ें। हर सदस्य को अलग, मजबूत अस्थायी पासवर्ड दें और उन्हें पहली बार लॉगिन के बाद पासवर्ड बदलने को कहें।

ज़रूरी: यह हिसाब-किताब ऐप है, वित्तीय/कानूनी सलाह नहीं। पहले खाली परीक्षण शीट में जाँच करें और शीट का सुरक्षित बैकअप रखें। पासवर्ड या असली सदस्य का निजी डेटा सार्वजनिक GitHub repository में न डालें।
